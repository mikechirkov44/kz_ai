## UAT — что прокликать перед приёмкой

### Подготовка
1. `docker compose up -d` — API `:8000`, UI `:5173`.
2. Войти под admin (из `.env`).
3. Админ → 1С: задать имя базы, URL, логин/пароль → «Проверить связь» → Синхронизация.
4. Убедиться, что есть `is_promo` у тестовых контрагентов.

### Данные
5. Загрузка Excel → скачать **Шаблон продаж** → открыть в Excel (не битый файл).
6. Загрузить небольшой файл; при ошибке — `errors.xlsx`.

### Отчёты
7. Мотивация: контрагент + месяц → таблица + Excel.
8. Оборачиваемость: 2–3 среза + период → матрица + Excel.
9. Квартальные планы: создать план → план/факт → итоговая матрица + комментарий.
10. Факт отгрузок: контрагент + квартал → сумма факта.
11. Рекомендации: список с severity; на дашборде видны топ-сигналы. Если LLM включён — блок «Совет ИИ».

### 1С UI
12. Номенклатура / Контрагенты: поиск, пагинация, модалка, Excel. Админ: закрепить менеджера.
13. Журнал документов: фильтр дат (месяц/год в календаре), вкладки, деталь в модалке.

### Shell / UX
14. Свернуть/развернуть сайдбар — состояние сохраняется после F5.
15. Сортировка таблицы по заголовку; ресайз колонки.
16. Выйти → войти снова; протухший токен ведёт на логин.
17. Не-админ не видит пункты Админ / Пользователи / Аудит.

### Опционально (staging)
18. Digest preview в админке.
19. Celery background sync (полный sync в очередь).
20. Пользователи: создать менеджера, деактивация.
21. Аудит: после login/sync появились записи.
22. Вторая (и следующие) базы 1С — имя в админке, sync по выбранному подключению.
