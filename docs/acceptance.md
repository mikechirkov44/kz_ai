## UAT — что прокликать перед приёмкой

### Подготовка
1. `docker compose up -d` — API `:8000`, UI `:5173`.
2. Войти под admin (из `.env`).
3. Админ → OData asil → «Проверить связь» → Инкремент или Полный sync.
4. Убедиться, что есть `is_promo` у тестовых контрагентов.

### Данные
5. Загрузка Excel → скачать **Шаблон продаж** → открыть в Excel (не битый файл).
6. Загрузить небольшой файл; при ошибке — `errors.xlsx`.

### Отчёты
7. Мотивация: контрагент + месяц → таблица + Excel.
8. Оборачиваемость: 2–3 среза + период → матрица + Excel.
9. Квартальные планы: создать план → план/факт → §5.4 блоки.
10. Факт отгрузок: контрагент + квартал → сумма факта.
11. Рекомендации: список с severity; на дашборде видны топ-сигналы.

### 1С UI
12. Номенклатура / Контрагенты: поиск, пагинация, модалка, Excel.
13. Журнал документов: фильтр дат (месяц/год в календаре), вкладки, деталь в модалке.

### Shell / UX
14. Свернуть/развернуть сайдбар — состояние сохраняется после F5.
15. Сортировка таблицы по заголовку; ресайз колонки.
16. Выйти → войти снова; протухший токен ведёт на логин.

### Опционально (staging)
17. Digest preview в админке.
18. Celery background sync.
19. Вторая база `miamor` — когда будет URL.
