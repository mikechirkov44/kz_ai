# Подключения 1С (несколько баз)

В админке можно завести любое число баз. У каждой — **имя** (так она видна в фильтрах), URL OData, логин и пароль.

1. Админ → вкладка **1С** → заполнить имя / URL / логин / пароль.
2. Включить чекбокс «Включено» → **Сохранить** → **Проверить связь**.
3. При необходимости **Добавить подключение** для следующей базы.
4. Вкладка **Синхронизация**: выбрать базу или «Все включённые» → Обновить данные / Полная синхронизация.

Через `.env` при первом старте создаются слоты, если заданы URL:

```
ODATA_ASIL_URL=https://.../odata/standard.odata/
ODATA_ASIL_USER=...
ODATA_ASIL_PASSWORD=...
ODATA_MIAMOR_URL=https://.../odata/standard.odata/
ODATA_MIAMOR_USER=...
ODATA_MIAMOR_PASSWORD=...
```

Имена в UI после этого можно сразу переименовать. После появления строки в БД приоритет у админ-настроек (не `.env`).

Фильтры «База» берут список из `GET /api/v1/odata/sources` (имя, без секретов). Технический `source_id` остаётся в данных синхронизации.

## Проверка связи

Локально (без вывода паролей):

```bash
python scripts/check_miamor_odata.py
```

Ожидается `miamor_ok status=200`. В UI — кнопка «Проверить связь» у подключения.
