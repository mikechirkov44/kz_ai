# Настройка OData в 1С (этап 0)

1. Открыть базу `test3_asil` в режиме предприятия.
2. Файл → Открыть → `PUBID_811834-ДоступныйСоставИнтерфейсаOData.epf`.
3. Включить сущности из `docs/odata-mapping.md`.
4. Убедиться, что у пользователя из `1c.txt` есть право на стандартный интерфейс OData (чтение нужных объектов).
5. Проверить в браузере / скриптом:
   `python scripts/fetch_odata_metadata.py`
6. При успехе появится `docs/odata-metadata.xml` — сверить маппинг.
