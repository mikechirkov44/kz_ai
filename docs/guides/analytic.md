# Руководство: Analytic

## Отчёты

1. **Мотивация** — месяц, свод по участникам акции или один клиент, Excel. **Оборачиваемость / Квартальные / Факт** — фильтры → сформировать → при необходимости **Excel**.
2. **Рекомендации** — правила (неликвиды, паттерны, ценовой арбитраж); при включённом LLM в админке — короткий совет модели. На дашборде — краткий блок топ-рекомендаций.
3. **Журнал документов** — реализации, возвраты, заказы, поступления из производства (серии). Период + база → Обновить → клик по строке.

## Справочники

- Номенклатура / Контрагенты — поиск, фильтр базы, экспорт Excel по текущему фильтру.

## Советы

- Для сверки с Excel-эталонами используйте те же периоды, что в примерах (часто 2023 Q1).
- Матрица оборачиваемости: 5 срезов + «Основной (SKU)».
- Квартальный итог — матрица цвет металла / ЖЦТ / тип изделия, комментарии и план след. квартала на экране «Квартальные планы».
