# Руководство: Regional director

## Квартальные планы

1. Аналитика → **Квартальные планы**.
2. Выбрать год и квартал → Обновить.
3. Добавить/обновить план: контрагент + сумма → Сохранить.
4. Смотреть план/факт/% и **итоговый отчёт по кварталу** (матрица цвет металла / ЖЦТ / тип изделия).
5. Экспорт: **Excel план/факт** и **Excel итоги**.
6. Комментарий в строке «Итого» — сохраняется история, в таблице виден последний.

## Факт отгрузок

- Экран **Факт отгрузок**: контрагент + год/квартал.
- Формула: реализации − возвраты; исключается неликвид ЖЦТ «Вывод» (по сериям из поступлений производства).

## Digest

- Еженедельная рассылка (пн 08:00 Asia/Almaty) настраивается в админке: состав письма и SMTP.
- Preview/force send — в админке.
