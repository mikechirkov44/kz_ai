## Ежемесячный цикл

1. **Загрузка Excel** → скачать шаблон продаж/остатков.
2. Заполнить файл (колонки как в шаблоне), загрузить за нужный год/месяц.
3. Если есть ошибки — скачать `errors.xlsx`, исправить, загрузить снова. История загрузок — на том же экране.
4. **Мотивация** → месяц (по умолчанию все свои акционные клиенты ★) → свод, клик по клиенту для строк, Excel.
5. **Оборачиваемость** → срез и период → «Сформировать» / Excel.

## Важно

- Видны только контрагенты, которых администратор закрепил за вами (поле «Менеджер»).
- Контрагент должен быть участником акции (`is_promo`). Если списка нет — обратитесь к администратору.
- Цена в Excel необязательна: подставится средняя реализация 1С × 1.70.
- Возвраты в оборачиваемости учитываются месяцем фактического возврата.

## Быстрые ссылки в UI

- Данные → Загрузка Excel  
- Аналитика → Мотивация / Оборачиваемость / Дашборд (теплокарта пролежки)
- 1С → Контрагенты (проверка магазинов и типа работы)
