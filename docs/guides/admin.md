# Руководство: Admin

## Подключение 1С

1. Данные → **Админ** → вкладка **1С**.
2. Имя базы, URL / логин / пароль → **Проверить связь**.
3. Чекбокс «Включено» → сохранить. «Добавить подключение» — ещё одна база.
4. Синхронизация: выбрать базу или все включённые → Обновить данные / Полная синхронизация / в очередь.

См. также [../second-base.md](../second-base.md).

## Пользователи и «свои клиенты»

1. Данные → **Пользователи** — создать менеджера (роль `manager`).
2. 1С → **Контрагенты** → карточка → «Закрепить менеджера».
3. Менеджер в отчётах и журнале видит только закреплённых клиентов.

## Участники акции

- В админке отметьте `is_promo` у контрагентов (поиск + чекбокс).
- Без флага отчёты мотивации/оборачиваемости по акции будут пустыми.

## Аудит

- Данные → **Аудит** — журнал действий (вход, синхронизация, загрузки, отчёты).

## Health, LLM и рассылка

- Health: API / DB / Redis / OData на дашборде и во вкладке «Состояние».
- LLM: вкладка в админке, OpenAI-совместимый API, ключ шифруется.
- Рассылка: вкладка «Рассылка» — что входит в письмо, SMTP, получатели, превью и отправка. Авторассылка пн 08:00, если включена.

## LLM для рекомендаций

1. Данные → **Админ** → вкладка **LLM**.
2. Адрес OpenAI-совместимого API (например `https://api.openai.com/v1`), модель, ключ.
3. **Проверить связь** → **Сохранить**, чекбокс «Включено».
4. На экране «Рекомендации» правила остаются текстом; модель добавляет короткий совет. Если API не ответил — только правила.

Ключ шифруется в БД, на клиент не отдаётся.

## Безопасность

- Секреты только в `.env` / админке (шифрование пароля OData, ключа LLM и пароля SMTP).
- Rate limit: login и API (см. runbook).
- После смены `SECRET_KEY` всем нужно войти заново.
