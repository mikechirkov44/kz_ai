# Руководство: Admin

## Подключение 1С

1. Данные → **Админ** → Подключения 1С.
2. URL / логин / пароль → **Проверить связь**.
3. Чекбокс «Включено» → сохранить.
4. Синхронизация: Инкремент / Полный sync / в очередь Celery.

Рабочая база сейчас — `asil`. Вторая (`miamor`) — см. [../second-base.md](../second-base.md).

## Участники акции

- В админке отметьте `is_promo` у контрагентов (поиск + чекбокс).
- Без флага отчёты мотивации/оборачиваемости по акции будут пустыми.

## Health и digest

- Health: API / DB / Redis / OData на дашборде и в админке.
- Digest: preview или отправка; без SMTP — только preview.

## Безопасность

- Секреты только в `.env` / админке (шифрование пароля OData).
- Rate limit: login и API (см. runbook).
- После смены `SECRET_KEY` всем нужно войти заново.
